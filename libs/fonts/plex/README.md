# IBM Plex Sans & Mono (bundled)

IBM Plex by IBM Corp., SIL Open Font License 1.1 (see `LICENSE`), taken
unmodified from `@fontsource/ibm-plex-sans` 5.3.0 (weights 400/500/600) and
`@fontsource/ibm-plex-mono` 5.3.0 (weights 400/500), latin subset.

Used only for the app's interface (not for the watermark): Plex Sans for
text, Plex Mono for numbers, coordinates and small labels. Loaded under the
family names `GeoStamp Plex Sans` / `GeoStamp Plex Mono` so the UI looks the
same on every device, offline.
