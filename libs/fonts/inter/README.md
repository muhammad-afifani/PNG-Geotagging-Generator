# Inter (bundled)

Inter by The Inter Project Authors (Rasmus Andersson), SIL Open Font License 1.1
(see `LICENSE`), taken unmodified from `@fontsource/inter` 5.3.0 (latin +
latin-ext subsets, weight 400).

Used as the default Template 2 font: the GPS Map Camera stamp from iPhone is
drawn in Apple's SF Pro, which may only be used on Apple platforms; Inter is
the closest freely licensed match (its glyph widths fit a real stamp with no
spacing adjustment). Loaded under the family name `GeoStamp Inter`.
