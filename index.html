GeoStampStudio

Watermark GPS & geotag untuk foto dokumentasi lapangan

Kamera di area kerja restricted (area proses/plant) umumnya tidak boleh merekam GPS, jadi foto dokumentasi tidak punya info lokasi. Tool ini menambahkan koordinat & tanggal ke foto agar tetap memenuhi ketentuan teknis SIMPEL PPU (wajib ada bukti geotag). Semua proses berjalan di browser — tidak ada foto yang diunggah ke server.

Watermark GPS

Titik mulai. Isi data lewat CSV, input manual, atau langsung dari folder foto. Atur tampilan sambil melihat preview di atas foto aslinya. Data & pengaturan di sini dipakai menu lain.

Tempel ke Foto

Watermark "dibakar" menyatu ke foto asli. Foto dipasangkan dengan data berdasarkan nama file atau urutan.

Geotag Metadata

Hanya menulis GPS + tanggal ke EXIF. Foto tetap bersih tanpa watermark, tapi propertinya berisi lokasi.

Buat CSV dari Foto

Ekstrak nama file, tanggal/jam, dan GPS dari EXIF ke tabel yang bisa dikoreksi — unduh sebagai CSV atau lanjutkan langsung.

Proses & download

0foto

Cara memeriksa hasilnya

Klik kanan foto → Properties → Details (Windows), atau buka di pengecek EXIF mana pun. Koordinat & tanggal yang kamu isi akan tercantum di sana.

Foto / folder

Tarik & lepas foto di sini, atau klik untuk memilih

JPG · PNG · HEIC

Tanggal & jam diambil dari EXIF (JPG), atau dari tanggal file kalau tidak ada — ditandai di kolom "Sumber". GPS di EXIF ikut diambil dan lokasinya dideteksi. Cek dulu baris bertanda File System: itu hanya perkiraan.
